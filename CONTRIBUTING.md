# Contributing to StartLens

Thank you for your interest in contributing!

## How to Contribute
1. Fork the repository.
2. Create a feature branch.
3. Make your changes, keeping the design philosophy in mind.
4. Test thoroughly.
5. Submit a pull request with a clear description.

## Design Philosophy
StartLens is a visual launcher, not a terminal tool. Changes that strip
its UI essence will not be accepted.

## Code of Conduct
Be respectful and constructive.
