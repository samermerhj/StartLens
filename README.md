# StartLens – Fast Application Launcher

**Version:** 1.0.0-beta  
**Author:** Samer Merhj <mjosak7@gmail.com>  
**License:** Apache License 2.0

StartLens is a stylish, keyboard-driven application launcher for Linux.  
It lets you launch apps instantly with `Super+Space`, organize them into
categories, pin favorites, and track your usage – all without touching
the mouse.

## Features
- Instant app launch with `Super+Space`
- Favorites, Most Used, Recent, and Categories
- Custom groups from LensClean
- Text and SVG icon customization
- Hidden apps manager
- Smooth animations and beautiful UI

## Installation
``` 
sudo dpkg -i startlens_1.0.0-beta_amd64.deb
```

Build from Source

``` 
mkdir build && cd build
cmake ..
make -j$(nproc)
sudo make install
```

Philosophy Protection

StartLens is designed with a unique visual experience. Any modification
that degrades it into a terminal‑style launcher is discouraged.
Please respect the design principles that make StartLens special.
